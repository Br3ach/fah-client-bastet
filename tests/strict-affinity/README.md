Client-owned strict FahCore launch tests. Windows: from a Visual Studio x64 terminal, run python tests/strict-affinity/run.py --cbang PATH_TO_ORIGINAL_PR_CBANG. The runner compiles the actual CoreProcess.cpp and links unchanged cbang. It verifies singleton and expanded process masks, including inheritance by new Windows threads, in the child and proves invalid masks never execute the payload. Linux checks include singleton and multi-LP pools and launches with closed standard file descriptors. Linux: python3 tests/strict-affinity/linux-native.py executes the extracted native launch body with real OS syscalls and lifecycle adapters.
